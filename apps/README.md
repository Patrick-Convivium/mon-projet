# Mini-apps

Ce dossier accueille les mini-applications du centre applicatif.

## Applications

- `paris-social-planner/` — Paris Social Planner.
- `qr-mail/` — générateur de QR code ouvrant la composition d'un e-mail vers `patrick.convivium@gmail.com`.

Chaque mini-app doit idéalement avoir son propre sous-dossier et un `index.html` d'entrée.
