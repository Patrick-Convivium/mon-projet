# mon-projet

Centre applicatif destiné à accueillir plusieurs mini-apps.

## Structure

- `apps/` — toutes les mini-applications.
- `apps/paris-social-planner/` — Paris Social Planner.
- `database/` — documentation et éléments liés aux données.
- `.github/workflows/deploy-pages.yml` — publication GitHub Pages.

## Paris Social Planner

Application web statique sans dépendance. La version actuelle propose des scénarios de journée complète, dates, tirage et favoris. Le détail du programme est dépliable directement dans la page.

## Publication

GitHub Pages publie le catalogue racine puis les mini-apps sous `apps/`.

URL attendue : `https://patrick-convivium.github.io/mon-projet/`
